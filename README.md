# PharmaAssist AI

Simple healthcare website with a keyword chatbot (Python Flask + HTML + CSS + JavaScript).

## Files
- app.py - Python code (chatbot answers)
- templates/index.html - web page
- static/style.css - design
- static/script.js - chat, store filter, file check

## Run
1. pip install -r requirements.txt
2. python app.py
3. Open http://127.0.0.1:5000

## Add a new answer
Add one more item in the `topics` list in app.py with keywords and an answer.

Note: this is a student project, not a medical service.
